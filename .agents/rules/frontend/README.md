# Frontend rule routing

These framework-neutral interface rules apply to user-facing HTML, templates,
components, styles, and browser behavior:

- `accessibility.md`: semantics, keyboard use, focus, and assistive technology
- `forms.md`: controls, validation, submission, and unsaved state
- `interaction.md`: animation, touch, pointer, and destructive interactions
- `content.md`: copy, typography, localization, and variable content
- `layout-and-images.md`: responsive layout, theming, and image behavior
- `performance.md`: browser rendering and resource-loading performance

Apply these together with framework-specific rules. Automated accessibility
checks supplement rather than replace keyboard, screen-reader, zoom, and
manual visual review.
