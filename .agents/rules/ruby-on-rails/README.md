# Ruby on Rails rule routing

These rules apply to the Rails application selected by the approved technology
profile:

- `controllers.md`: controllers, routes, and request behavior
- `models.md`: Active Record models and factories
- `services.md`: application services and workflow orchestration
- `queries.md`: scopes and query objects
- `policies.md`: Pundit policies and authorization
- `migrations.md`: migrations, schema dumps, and data rollout
- `jobs.md`: Active Job and Solid Queue
- `mailers.md`: Action Mailer
- `views.md`: views, ViewComponent, Turbo, and Tailwind CSS
- `testing.md`: RSpec, FactoryBot, Shoulda Matchers, and system tests
- `security.md`: Rails-specific security controls
- `tooling.md`: Rails development and validation commands

Planner, developer, and reviewer must select every file relevant to the task;
directory placement is not a substitute for reading the applicable rule.
View work also requires the framework-neutral `frontend/` rules and, when
JavaScript changes, `javascript/` rules.
